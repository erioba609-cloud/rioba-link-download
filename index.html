How to install

  1. Tap Download for Android and save the file.
  2. Open the downloaded RIOBA-LINK.apk.
  3. If Android asks, allow Install unknown apps for your browser or Files app.
  4. If you see Harmful app blocked, don't worry. See the orange box below and tap Install anyway.
  5. Open RIOBA LINK and share with a friend.

Saw "Harmful app blocked"? It's safe, here is how to continue

RIOBA LINK is brand new and is not on the Play Store yet, so Google Play Protect shows this message for any new app it has not seen before. It does not mean the app is harmful.

  1. On the blocked message, tap More details.
  2. Tap Install anyway.
  3. Wait for the install to finish, then tap Open.

Don't see Install anyway? Open Play Store, tap your profile picture, then Play Protect and the gear icon. Turn off Scan apps with Play Protect only for the install, then turn it back on after.

Says "Install blocked" or "Not allowed"?

  1. Tap Settings on that message.
  2. Turn on Allow from this source (it names your browser or Files app).
  3. Go back and open RIOBA-LINK.apk again, then tap Install.

Download stopped at the end? Switch to Wi-Fi or a strong signal, delete the unfinished file and download again.
